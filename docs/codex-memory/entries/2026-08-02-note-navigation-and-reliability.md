# 笔记替换文章入口与可靠性修复

## 需求背景

小程序原有文章能力因审核原因默认隐藏，私人笔记需要替代文章成为稳定的主要入口；文章仍由 `render.compatibility` 配置决定是否显示。

## 本次处理

- 在原生与自定义底部导航中增加固定的“笔记”入口，文章入口继续按配置显示。
- 笔记页调整为 Tab 页面，首页进入笔记时使用 `wx.switchTab`。
- 保存失败时保持编辑状态，避免用户误认为内容已经同步。
- 恢复本地草稿时同步 Markdown 阅读节点、文件夹和标签选中状态。
- 阅读页将“编辑笔记”放在“更多”之前，空正文保持空白，不展示占位文案。
- 笔记列表按每页 20 条加载，支持触底追加并展示加载状态。
- 笔记列表与首页一致，直接在滚动内容容器上预留 `156rpx + safe-area-inset-bottom` 的底部内边距，避免末尾内容被悬浮导航遮挡。
- 自定义 Tab 去掉额外的 `18rpx` 底部留白，仅保留设备安全区，减少真机上与屏幕底部的距离。
- 笔记接口遇到 `10007/10010` 时自动刷新微信会话并仅重试一次；追加分页失败时保留已有列表，仅显示轻提示。
- 移动端多级文件夹采用“当前层子文件夹 + 面包屑 + 底部树形抽屉”：进入文件夹后按 `folderId` 查看直接笔记，新建笔记自动归入当前位置，并支持在当前位置创建子文件夹。
- 根目录保留“全部笔记”和“未分类”虚拟入口；回收站隐藏活动文件夹导航，避免普通目录与删除状态混用。
- 笔记卡片展示后端 `contentPreview` 正文摘要；文件夹数量因接口暂未返回统计值而不展示。
- 文件夹区域不重复展示当前文件夹标题和面包屑；“切换 / ＋文件夹”放在“全部 / 置顶 / 回收站”筛选栏右侧，回收站中隐藏。
- 筛选按钮禁止 Flex 收缩和文字换行，并缩小横向间距，避免真机窄屏将“全部 / 置顶 / 回收站”拆成两行。
- 笔记列表、详情和分类管理不再使用原生 `picker/showModal/showActionSheet`，统一为带安全区、选中态和危险操作样式的自绘底部弹层。
- 输入、确认和预览使用屏幕居中卡片，操作与选择列表使用底部抽屉；遮罩使用显式四边定位，避免部分真机不识别 `inset` 后弹层跑到顶部。
- 子文件夹横向滚动区设置与卡片匹配的明确高度，并移除多余外层底板，避免滚动容器塌缩后出现空白圆角条和卡片溢出。
- 选项较少的“更多操作”菜单改为居中卡片；可能包含大量项目的文件夹选择仍使用底部抽屉。
- 放大居中菜单的标题、选项字号与行高，并增加卡片式点击反馈；笔记设置和历史版本也改为居中卡片，长历史列表在卡片内部滚动。
- 弹窗取消、确认和抽屉创建按钮统一使用 Flex 双向居中，清除小程序原生按钮内边距与伪边框，避免文字基线视觉下沉。
- 历史版本预览改为独立居中卡片，使用正文同款 Towxml Markdown 渲染；预览时隐藏历史列表，关闭后返回历史列表，避免双层弹窗叠加和原文链接裸露。
- 点击历史记录默认直接预览，预览底部固定提供恢复、删除、返回；预览卡片扩大到 `700rpx / 90vh`，正文滚动区提高到 `64vh`。
- 笔记设置中的文件夹选择复用多级目录逻辑：保留未分类，按父子顺序排列并通过图标和 `32rpx` 层级缩进展示，不再使用拍平列表。
- 快捷菜单选项通过 `itemsJson` 字符串传入并在组件内解析，绕开部分真机自定义组件数组属性更新后渲染为空的问题；三点图标改为 CSS 圆点，消除字体差异。
- Skyline 下仅设置 `max-height` 的 `scroll-view` 会塌缩为 0：短操作菜单改用普通 `view` 自然撑高，只有文件夹选择使用明确 `52vh` 高度的滚动容器。
- “全部 / 置顶 / 回收站”显示数量徽标；当前范围复用列表 `total`，另外两个范围各请求 1 条取得 `total`，数量跟随当前文件夹和搜索条件更新。
- 增加 `tests/note-page.test.js`，覆盖上述关键行为。
