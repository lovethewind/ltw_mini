# 小程序直接注册账号与统一登录

个人中心未绑定状态下点击新用户入口，整行“点击填写用户名和密码，完成注册”使用红色加粗提示，随后展开表单填写用户名、密码和选填昵称；小程序请求层在昵称未填时直接发送用户名作为昵称，不改后端。用户名输入框失焦时调用公共账号存在性接口，已存在时显示红色提示并阻止提交，提交接口仍保留最终唯一性校验。注册和账号密码登录都保存同一个普通用户 token 到 `ltw_token`，随后切换到笔记页；退出登录同时清理普通 token 与历史 `ltw_note_token`。注册成功后设置一次性刷新标记，笔记页进入时重新拉取列表，个人中心下次显示时重新拉取账号状态。个人中心有 token 时调用 `/user/info`，无 token 时才通过 `wx.login` 调用微信用户信息接口；笔记接口只接受普通用户 token，不再发送 `x-note-session`。用户名 3-20 位、密码 6-30 位，登录/注册中禁止重复提交。
